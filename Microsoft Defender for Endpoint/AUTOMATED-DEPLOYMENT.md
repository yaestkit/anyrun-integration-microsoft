# Установка коннекторов ANY.RUN для Microsoft Defender for Endpoint

Тестовый вариант от 2026-10-05. Распакуйте архив **в корень репозитория с заменой файлов**, без дополнительной папки. Архив обновляет установщик в `Scripts/` и эту инструкцию; код коннекторов и корневой README не заменяются.

Нужны PowerShell 7.4+, интернет и учётная запись пользователя с необходимыми правами в Azure и Entra. Шаблоны и пакеты функций скачиваются с закреплённого коммита, проверяются по SHA-256 и не требуют ручной сборки. В этом тестовом варианте источник — форк yaestkit.

Из корня репозитория:

```powershell
pwsh -File "./Microsoft Defender for Endpoint/Scripts/Deploy-ANYRUNMDEConnector.ps1" -Connector Both -InstallMissingModules
```

Для одного коннектора замените `Both` на `Sandbox` или `Feeds`. Без `-Connector` появится меню. `-InstallMissingModules` разрешает установку недостающих модулей Az/Graph из PSGallery в область CurrentUser; если модули уже установлены, флаг не нужен.

Для заранее выделенной группы ресурсов:

```powershell
& "./Microsoft Defender for Endpoint/Scripts/Deploy-ANYRUNMDEConnector.ps1" `
  -Connector Feeds -UseExistingResourceGroup `
  -ResourceGroup rg-security-integrations -Region westeurope `
  -Tags @{CostCenter='SEC-1';Environment='Production'}
```

Новую группу скрипт по умолчанию создаёт в eastus. Для существующей группы учитывается её регион и регион уже созданных ресурсов; итоговый регион выводится до подтверждения установки.

Запускайте последовательно: каждый обычный запуск повторно применяет шаблоны выбранных коннекторов. Действующий секрет переиспользуется; ротация требует `-RotateSecret`. Установки, созданные другими версиями установщика, автоматически не импортируются.

[Полная инструкция и ограничения](Scripts/README.md). Перед использованием в продуктивном тенанте требуется живой тест: локальные проверки используют моки Azure/Graph.

Рядом со скриптом находится `.sha256` для проверки целостности копии; это не подпись издателя. Архив не включает модули PowerShell и не является автономным установщиком без интернета.
